# Security policy

## Supported versions

Security fixes, when made, are released on the latest version of `videojs-mobile-ui`. Older versions do not receive backports.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/mister-ben/videojs-mobile-ui/security/advisories/new) to send a private report. Please give the maintainer a chance to review the report before sharing details publicly.

Include the affected plugin and Video.js versions, the browser or environment, the steps to reproduce the issue, and its impact. If your report concerns a dependency, explain how the plugin or its build process is affected.

This is a maintenance-only project. Reports are reviewed as time permits.
